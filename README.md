# GREENOUT - Laboratorio de Programacao

Exercícios pequenos com testes, organizados por linguagem.

| Pasta | Conteúdo |
|-------|----------|
| `python/` | Algoritmos e estruturas de dados (FizzBuzz, ordenação, pilha, fila...) |
| `sql/` | Schema de exemplo e consultas (JOIN, agregação, subconsulta) |
| `powershell/` | Scripts utilitários (arquivos, logs, renomeação) |
| `tests/` | Testes `unittest` para Python e SQL (via SQLite) |

## Rodando os testes

```sh
python -m unittest discover -s tests -v
```
